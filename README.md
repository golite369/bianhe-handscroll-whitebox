# 汴河入画 · 白盒 Demo

用于验证二维长卷场景、人物行走、NPC 动态、船只交互及水面表现的个人实验。

## 本地运行

在项目目录运行 `python -m http.server 8777 --bind 127.0.0.1 --directory dist`，然后打开 http://127.0.0.1:8777/。

左右方向键控制人物，E 键互动，空格暂停。网页开头可选择街区。
