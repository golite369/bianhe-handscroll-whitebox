# 汴河寻踪

一款以宋代市井长卷为舞台的二维网页探索游戏。

你扮演携带画具的沈照，沿汴河寻找没有如约出现的张择端。从茶铺的一张画稿出发，登船问路、查看货单、寻回青布纸包，在与船夫、伙计和蜀商的交谈中，慢慢了解交子与普通人的生活。

这里不以高难度解谜为中心，而是让玩家走进画卷：听街边招呼，停下喝茶，到酒楼点菜，亲手数钱，再顺着眼前的线索继续寻找。

## 当前内容

- 动态彩色长卷：横向漫游、行走的 NPC、船与船夫、水面与天气表现。
- 寻访画师主线：茶铺问人 → 乘船打听 → 调查货单 → 岸边寻物 → 找到张择端 → 归还纸包。
- 近景对话：镜头靠近人物，暂时锁定主角移动；逐字显示，点击全文或继续翻页。
- 物品展示：画稿、货单、青布纸包与游戏交子示意图随对应事件展示。
- 市井闲趣：茶铺饮茶、酒楼点菜与找零、蜀客见闻、铁钱与交子兑换及兑回。
- 地点触发：经过店门或对应人物收到招呼，任务列表指路，不替代现场探索。
- 会话进度：主线与钱袋保存在当前浏览器会话中。

当前为桌面网页 Demo，围绕不少于三分钟的主线体验设计；实际时长取决于阅读、行走和支线选择，暂不以手机端为目标。

## 操作

| 操作 | 按键或入口 |
| --- | --- |
| 左右行走 | A / D 或 ← / → |
| 交谈与附近互动 | E 或点击人物附近按钮 |
| 对话继续 | 点击对话框；支持 Enter、空格、E |
| 浏览场景 | 点击街道前往、拖动浏览 |
| 暂停街市动画 | 空格或暂停按钮（交谈时用于推进对白） |
| 关闭对话或物品窗口 | Esc 或关闭按钮 |
| 声音 | 主场景右下角；酒楼有独立音乐按钮 |

## 本地运行

无需游戏引擎、依赖安装或编译。在仓库根目录运行：

```sh
python -m http.server 8777 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8777/ 。请使用 HTTP 服务，不要直接双击 HTML 文件。

## 仓库内容

`dist/` 包含可运行版本的 HTML、JavaScript、CSS、图片及本地 Three.js 文件；`docs/` 包含剧情、台词、玩法、道具记录和开发说明；`tests/` 包含主要交互与状态测试；`scripts/` 包含文档整理工具。

主线台词与分支已包含在源码中，文档同步整理现有实现。典当、更多娱乐及后续章节尚未实现，不作为已有功能宣传。

## 背景与素材

人物相遇和任务情节为游戏创作；兑换支线采用周六讲述的虚构蜀地经历。游戏价格及交子图像为体验设定，不是历史物价、汇率或真券复刻。

场景与基础交互参考 [qingming-riverside](https://github.com/xianxie6/qingming-riverside)。版本及素材记录见 [REFERENCE.md](REFERENCE.md)，随项目保留原许可与第三方署名文件。
