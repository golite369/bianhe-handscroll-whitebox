# 汴河寻踪 · 玩法与体验

## 游戏循环

进入长卷 → 行走观察 → 靠近人物或地点 → 交谈/调查 → 获得线索 → 前往下一处。主线之外可饮茶、吃饭与体验交子兑换。

## 任务面板

左侧“行记”显示主线目标、闲趣入口与钱袋，可折叠。闲趣列表指引到地点，不从远处直接开启店铺体验。船上暂时禁用街边闲趣入口。

主线按序推进，重复触发不跳关。中断对话不算完成；调查窗口的明确确认选项才推进调查。

## 对话与物品

- 对话镜头靠近主角与目标人物，锁定主角移动，结束后恢复探索。
- 台词逐字显示，点击先展开本页全文，再点击翻页或继续。
- 长对白依据实测字宽分页，不一次堆满大框。
- 画稿、货单、青布纸包、交子在对应事件窗口按原图比例展示。
- 与王五交谈时增强其视觉突出度，结束后恢复。
- UI 使用简约纸色与淡墨风格，现场喊话与正式对白相协调。

## 钱袋

初始生活钱袋 200 文，茶钱五文，酒楼账单按选择计算，均为游戏设定。找零正确才扣饭钱，已付账单不重复扣款。

兑换支线有独立的一包剧情铁钱，兑换后为一张交子，兑回后恢复铁钱。不增加生活钱袋，也不作为汴京酒楼付款方式。

## 环境体验

保留动态 NPC、渡船、喂鸟、桥边事件、夜景、清明时雨、放大与声音控制，和主线并行。保留的中秋模块目前默认关闭，不列为正常入口可玩内容。

## 进度

主线存储键 `handscroll-main-v1`，钱袋键 `handscroll-wallet-v1`，均使用 `sessionStorage`。这是浏览器会话内存档，不是账户云存档；刷新可保留，关闭会话后的行为由浏览器决定。

船上阶段重载退回登船阶段，以避免临时船只状态丢失。酒楼“重新入店”重置当次用餐，不承诺清空所有主线及钱袋。完整重玩可用独立的新浏览器会话。

## 范围

面向桌面键盘鼠标，不承诺手机操作。没有战斗、等级、联网交易或复杂金融模拟；不必掌握货币史才能完成主线。
