# 汴河寻踪 · 剧情与任务流程

本文对应当前已实现版本。完整主线对白见 [DIALOGUE.md](DIALOGUE.md)，支线文本见 [market-experiences.js](../dist/src/market-experiences.js)。

## 故事设定

沈照带着画具到茶铺赴约，张择端却已离开。他不是卷入凶案，也不是故意设谜：船夫收绳、伙计搬货、蜀商讲交子，这些日常细节让他不断停下来观察。玩家沿他的踪迹，在轻松寻人故事中认识河岸生活。

体验重点是“慢他一步，却逐渐看懂他在看什么”。画稿、船篷、货单、青布、木板和绳结是具体线索，不依赖冷僻知识作答。

## 人物

| 人物 | 身份与作用 |
| --- | --- |
| 沈照 | 玩家角色，携画具赴约，观察并追问 |
| 王五 | 茶铺伙计，交出画师留下的画稿 |
| 赵三 | 船夫，提供画师去向和纸货信息 |
| 搬货伙计 | 桥头摊棚伙计，说明包裹辨认方法 |
| 张择端 | 观察市井生活的画师，寻访目标 |
| 周六 | 蜀商、纸包主人，讲携钱与交子的经历 |
| 酒楼伙计、蜀客 | 支线生活互动与货币见闻参与者 |

## 主线骨架

| 阶段 | 玩家行动 | 信息与推进条件 |
| --- | --- | --- |
| tea | 到茶铺找王五 | 获得圈出带篷船的画稿；完成交谈 |
| ride | 到河岸招船、登船 | 上船后进入船上问路阶段 |
| boat | 向赵三问路 | 画师跟纸货去桥头；完成对白 |
| invoice | 查看船上货物 | 货单写桥头摊棚；记下去处并收好 |
| landing | 随船靠岸、下船 | 东岸靠泊且主角下船到岸上 |
| stall | 向搬货伙计打听 | 画师还在附近，包裹特征是青布与木板 |
| search | 调查摊棚 | 找到木板上的青布纸包，收好 |
| zhang | 找到张择端 | 他因观察日常忘了赴约，托玩家归还纸包 |
| return | 将纸包交给周六 | 听他区分货单、交子与认账规矩；完成交谈 |
| complete | 返回画卷 | 可继续交谈或体验闲趣 |

错误调查不惩罚：布匹旁有交货木签，竹筐里有麻绳和旧布。凭青布与木板最终找到包裹。船上还可看垫纸木板，以及画着握橹手和绳结的草稿；这些补充环境故事，不改变答案。

## 市井闲趣

### 茶铺歇脚

经过王五附近听到喊话。选择付五文，扣游戏茶钱，再去饮茶；可听蜀客谈携带铁钱的辛苦。不阻塞主线。

### 酒楼一席

店门进入孙羊正店，落座点菜。结账时计算找零，错误可重试，正确才扣款。已结清的一席不重复扣钱。离开直接返回长卷，不需再穿过室内路线。

### 周六的蜀地旧事

经过周六触发交子见闻。由他讲往事，玩家进入虚构蜀地兑铺情境：交出一包剧情铁钱 → 领取等值体验交子并看图 → 收好或兑回。持有交子时可再次进入柜台查看。

剧情铁钱与汴京生活钱袋分开，不扣茶饭用的铜钱，不重复领出多张交子。

## 交子主题

先分清“货单写去处”，再理解“交子减轻携钱负担，但要有认账规矩”。不将其设计为汴京所有商铺通用的支付道具，也不编造固定历史兑换比例。

## 后续方向（未实现）

典当、购买其他纸币、更多宋代娱乐与后续章节尚未接入。扩展仍宜采用地点触发、短小生活事件和具体物证，避免把轻探索变成知识考试。
